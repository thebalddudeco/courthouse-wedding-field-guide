# Courthouse Wedding Field Guide

A touch-friendly, interactive production guide for photographing two courthouse weddings in one day.

## Live site

**https://thebalddudeco.github.io/courthouse-wedding-field-guide/**

The guide includes separate Wedding A and Wedding B workspaces, progress tracking, exact posing prompts, courthouse and family coverage, street-photo reminders, section notes, a quick-reference mode, and offline caching after the first visit.

## Data and privacy

Checkmarks, identifiers, schedules, and notes stay in the browser's local storage on the device where they are entered. They are not committed to this repository or sent to a database. Clearing browser website data will clear the saved guide state.

## iPad use

Open the live site in Safari once while online. Use **Share → Add to Home Screen** for an app-like shortcut. After the first successful visit, the core guide is cached for offline use.
