# ActiveShot Asset Manifest

## Logos

| Asset | Format | Best use |
|---|---|---|
| Horizontal light | SVG + PNG | Light website sections, documents, partner pages |
| Horizontal dark | SVG + PNG | Dark website sections, video cards, event screens |
| Stacked light | SVG | Centered and square layouts on light backgrounds |
| Stacked dark | SVG | Centered and square layouts on dark backgrounds |
